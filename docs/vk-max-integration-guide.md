# Введение

Данное руководство описывает процесс подключения каналов **ВКонтакте (VK)** и **Max Messenger** к платформе **AI Agents CRM**. После настройки ваш AI-агент будет автоматически отвечать на сообщения пользователей в этих каналах — так же, как в Telegram, Instagram и WhatsApp.

## Что поддерживается

| Функция | ВКонтакте | Max Messenger |
|---|---|---|
| Текстовые сообщения | ✓ | ✓ |
| Фотографии / изображения | ✓ | ✓ |
| Видео | ✓ | ✓ |
| Документы / файлы | ✓ | ✓ |
| Голосовые сообщения (STT) | ✓ | ✓ |
| Inline-кнопки (callback) | ✓ | ✓ |
| Ссылочные кнопки | ✓ | ✓ |
| Ссылка на оплату | ✓ | ✓ |
| Команды бота (/start, /help…) | ✓ | ✓ |

# Подключение ВКонтакте (VK)

## Что потребуется

Перед началом убедитесь, что у вас есть:

- Аккаунт ВКонтакте с правами **руководителя** или **администратора** в нужном сообществе
- Доступ к администраторской панели AI Agents CRM

---

## Шаг 1. Создайте или откройте сообщество ВКонтакте

1. Войдите в ВКонтакте.
2. Перейдите в раздел **«Сообщества»** → **«Создать сообщество»** (или откройте уже существующее).
3. Выберите тип сообщества — **«Бизнес»** или **«Группа»**.

> **Важно:** Личные страницы и мероприятия не поддерживают Callback API. Нужно именно сообщество.

---

## Шаг 2. Включите сообщения в сообществе

1. Откройте сообщество → **«Управление»**.
2. Перейдите в **«Сообщения»**.
3. Включите переключатель **«Сообщения сообщества»**.
4. Нажмите **«Сохранить»**.

---

## Шаг 3. Получите токен сообщества

1. В управлении сообществом перейдите в **«Работа с API»**.
2. Нажмите **«Создать ключ»**.
3. Отметьте следующие разрешения:
   - ✓ **Сообщения сообщества** (обязательно)
   - ✓ **Фотографии** (для отправки изображений)
   - ✓ **Документы** (для отправки файлов)
   - ✓ **Управление** (необязательно, для расширенных функций)
4. Подтвердите через SMS или код подтверждения.
5. **Скопируйте и сохраните токен** — он показывается только один раз.

---

## Шаг 4. Узнайте ID сообщества

1. В адресной строке браузера откройте вашу страницу сообщества.
2. Если URL вида `vk.com/club123456789` — то `123456789` и есть Group ID.
3. Если у сообщества есть красивый адрес (`vk.com/mygroup`):
   - Откройте **«Управление»** → **«Настройки»**
   - Посмотрите поле **«ID сообщества»**
   - Или воспользуйтесь сервисом [vk.com/dev/api](https://vk.com/dev/api): метод `groups.getById`

---

## Шаг 5. Настройте Callback API — первый этап (получение кода подтверждения)

1. В управлении сообществом перейдите в **«Работа с API»** → **«Callback API»**.
2. Нажмите **«Добавить сервер»** или выберите существующий.
3. В поле **«URL»** введите адрес вебхука — его вы получите на следующем шаге в платформе.
4. Запишите **«Строку для подтверждения сервера»** — она появляется прямо на этой странице. Это ваш `confirmation_code`.

> **Не нажимайте «Подтвердить»** пока не настроите платформу — сначала нужно ввести код в платформу, иначе подтверждение не пройдёт.

---

## Шаг 6. Настройте в платформе AI Agents CRM

1. Войдите в **AI Agents CRM** как администратор.
2. Перейдите в **«Агенты»** → выберите нужного агента → **«Каналы»**.
3. Нажмите **«Добавить канал»** → выберите **«ВКонтакте»**.
4. Заполните форму:

| Поле | Что вводить |
|---|---|
| **Group ID** | Числовой ID сообщества (из Шага 4) |
| **Community Token** | Токен из Шага 3 |
| **Confirmation Code** | Строка из Шага 5 |
| **Webhook Secret** | Придумайте любую секретную строку (например, `mYs3cr3t`) — потом введёте её же в VK |

5. Нажмите **«Подключить»**.
6. **Скопируйте Webhook URL** — он появится после сохранения (вида `https://your-app.railway.app/api/v1/vk/webhook/{binding_id}`).

---

## Шаг 7. Завершите настройку Callback API в VK

1. Вернитесь в ВКонтакте → **«Работа с API»** → **«Callback API»**.
2. В поле **«URL»** вставьте скопированный Webhook URL.
3. В поле **«Секретный ключ»** введите тот же `Webhook Secret`, что вы указали в платформе.
4. В разделе **«Типы событий»** включите:
   - ✓ **Входящее сообщение** (`message_new`)
   - ✓ **Нажатие на кнопку** (`message_event`) — для inline-кнопок
5. Нажмите **«Подтвердить»**.

> Если подтверждение прошло успешно — VK получил от платформы строку `confirmation_code` и соединение установлено.

---

## Шаг 8. Верификация в платформе

1. Вернитесь в **AI Agents CRM** → **«Каналы»**.
2. Рядом с каналом ВКонтакте нажмите **«Проверить»** или **«Verify»**.
3. Платформа вызовет API VK и проверит, что токен и Group ID корректны.
4. Статус изменится на **«Активен»** (зелёный).

> Если возникла ошибка — проверьте токен и Group ID. Убедитесь, что сообщения сообщества включены (Шаг 2).

---

## Готово! Проверка работы

Напишите сообщение в ВКонтакте на страницу вашего сообщества — AI-агент должен ответить автоматически.

# Подключение Max Messenger

## Что потребуется

- Аккаунт в Max Messenger (приложение доступно в App Store и Google Play)
- Доступ к администраторской панели AI Agents CRM

> **О Max Messenger:** Max — мессенджер от Mail.ru Group. Боты создаются через специального бота `@BotMaster` прямо в приложении.

---

## Шаг 1. Создайте бота в Max Messenger

1. Откройте **Max Messenger** на смартфоне или веб-версию.
2. В строке поиска найдите и откройте бот **`@BotMaster`**.
3. Нажмите **«Создать бота»** (или отправьте команду `/newbot`).
4. Введите **имя бота** — то, что увидят пользователи (например, `Vet Doctor Assistant`).
5. Введите **username бота** — уникальный идентификатор, начинается с маленькой буквы, содержит только латиницу и цифры (например, `vetdoctorassistant_bot`).
6. После создания `@BotMaster` пришлёт вам **токен** вида:

```
001.1234567890.abcdef1234567890abcdef1234567890
```

7. **Сохраните токен** — он потребуется на следующем шаге.

---

## Шаг 2. Узнайте Bot ID (необязательно, платформа найдёт сама)

Bot ID определяется автоматически при верификации. Если вам нужно узнать его вручную:

1. Отправьте GET-запрос к API:
```
GET https://botapi.max.ru/me?access_token=ВАШ_ТОКЕН
```
2. В ответе найдите поле `"user_id"` — это и есть Bot ID.

---

## Шаг 3. Настройте в платформе AI Agents CRM

1. Войдите в **AI Agents CRM** как администратор.
2. Перейдите в **«Агенты»** → выберите нужного агента → **«Каналы»**.
3. Нажмите **«Добавить канал»** → выберите **«Max Messenger»**.
4. Заполните форму:

| Поле | Что вводить |
|---|---|
| **Bot Token** | Токен из Шага 1 |
| **Bot Username / ID** | Username бота без `@` (например, `vetdoctorassistant_bot`) |
| **Webhook Secret** | Придумайте любую секретную строку — платформа передаст её в Max автоматически |

5. Нажмите **«Подключить»**.

> Платформа автоматически зарегистрирует webhook в Max Bot API и проверит токен. Ручная настройка на стороне Max не требуется.

---

## Шаг 4. Автоматическая верификация

В отличие от VK, Max выполняет верификацию **автоматически** при нажатии «Подключить»:

1. Платформа вызывает `GET /me` — проверяет токен.
2. Регистрирует webhook (`POST /subscriptions`).
3. Устанавливает команды бота (`POST /bots/my/commands`).
4. Статус канала сразу меняется на **«Активен»**.

Если верификация не прошла — проверьте корректность токена.

---

## Готово! Проверка работы

Найдите вашего бота в Max Messenger и напишите ему — AI-агент должен ответить автоматически.

# Команды бота

Оба канала поддерживают стандартные команды бота. Они работают одинаково в VK и Max:

| Команда | Описание |
|---|---|
| `/start` | Начало диалога / приветствие |
| `/restart` | Сброс контекста, новый диалог |
| `/help` | Справка и список доступных команд |

> Команды настраиваются в разделе **«Настройки агента»** в платформе.

# Медиафайлы

## ВКонтакте

| Тип | Поведение |
|---|---|
| Изображение | Загружается на сервера VK, пересылается агенту как URL |
| Видео | Ссылка извлекается из attachment |
| Документ/файл | Загружается через VK Documents API |
| Голосовое сообщение | Транскрибируется через STT-сервис и передаётся агенту как текст |

## Max Messenger

| Тип | Поведение |
|---|---|
| Изображение | URL из payload передаётся агенту напрямую |
| Видео | Загружается через Max /uploads API |
| Документ/файл | Загружается через Max /uploads API |
| Голосовое сообщение | Транскрибируется через STT-сервис и передаётся агенту как текст |

# Платёжная ссылка

Если в настройках агента включена опция **«Ссылка на оплату»** (External Link), при достижении лимита бесплатных сообщений или при команде оплаты пользователь получит:

- Сообщение с описанием тарифных планов
- Кнопку **«Перейти к оплате»** — inline-кнопка со ссылкой на страницу оплаты

Настройка производится в разделе **«Оплата»** → **«Провайдер: Внешняя ссылка»** → указать URL платёжной страницы.

# Частые вопросы

## VK: Сообщество не получает сообщения

- Убедитесь, что **«Сообщения сообщества»** включены (Шаг 2).
- Проверьте, что токен имеет право **«Сообщения сообщества»**.
- Убедитесь, что Callback API подтверждён (Шаг 7) — статус рядом с URL сервера должен быть зелёным.

## VK: Ошибка подтверждения Callback API

- Убедитесь, что в платформе введён правильный `Confirmation Code` (Шаг 5–6).
- Webhook URL должен быть доступен из интернета (не localhost).
- Проверьте, что `Webhook Secret` в VK и в платформе совпадают.

## Max: Бот не отвечает

- Убедитесь, что токен корректный и не истёк.
- Попробуйте переподключить канал (удалить и добавить заново) — это перерегистрирует webhook.
- Убедитесь, что приложение задеплоено и доступно из интернета.

## Max: Ошибка при подключении

- Проверьте, что `Bot Username` введён без символа `@`.
- Токен должен быть именно для **бота**, созданного через `@BotMaster`, а не аккаунтный токен.

## Как изменить токен?

1. В платформе удалите существующее подключение канала.
2. Создайте новое подключение с обновлённым токеном.
3. Для VK — повторите Шаги 5–8 (Callback API нужно переподтвердить).
4. Для Max — подключение автоматически зарегистрирует новый webhook.
